## Sobre o projeto
Simulador da MiniCPU implementando o ciclo Fetch-Decode-Execute em C.
Desafio: Somatório de array.

O programa soma 8 valores pré-carregados na memória com os endereços sendo 0x10-0x17
gravando o resultado em 0x20.

## Linguagem
C

## Como executar
```bash
gcc main.c -o simulador
./simulador
```

## Validação
Resultado esperado: soma = 36
